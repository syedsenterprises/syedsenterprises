# Syed's Enterprises — React 3D website

## Run locally
1. Install Node.js (18.18+ recommended).
2. Open this folder in VS Code / terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build
`npm run build` creates the production site in `dist/`.

## Included
- React + Vite application
- Three.js / React Three Fiber animated globe
- CSS 3D venture carousel with hover focus, click-to-open links, arrows and touch swipe
- Responsive sections for ecosystem, ventures, services, products, roadmap, founder and contact
- Founder hologram artwork supplied in `public/founder-hologram.png`

## Before publishing
- Confirm the public founder name, biography and portrait are approved for publication.
- Confirm all venture descriptions and destination URLs.
- Replace `hello@syedsenterprises.org` with a monitored email address if needed.
- Review the legal wording, privacy policy, terms and business contact details.
- The site has not been deployed and the domain DNS has not been changed.
- Google Fonts is used for typography; remove the @import in `src/styles.css` for a fully self-hosted font stack.

## Notes
The roadmap is deliberately directional and contains no fabricated dates, user counts, client claims or revenue claims. The venture carousel and navigation are functional; external venture links open in a new tab.
